# PanelLabels

Web εφαρμογή για ηλεκτρολόγους: σχεδιασμός σειρών ηλεκτρικού πίνακα και εκτύπωση ετικετών σε πραγματικές διαστάσεις (1 μονάδα = 17,5 mm, ρυθμιζόμενο).

Δεν χρειάζεται server, βάση δεδομένων ή συνδρομή. Όλα τα δεδομένα μένουν στη συσκευή του χρήστη. Δουλεύει και χωρίς internet μετά το πρώτο άνοιγμα.

## Αρχεία

| Αρχείο | Τι κάνει |
|---|---|
| `index.html` | Η σελίδα της εφαρμογής |
| `app.js` | Οθόνες, έργα, αποθήκευση, αντίγραφα ασφαλείας |
| `render.js` | Σχεδίαση ετικετών σε χιλιοστά και δημιουργία PDF (χωρίς εξωτερικές βιβλιοθήκες) |
| `styles.css` | Εμφάνιση |
| `manifest.webmanifest`, `icons/` | Όνομα και εικονίδιο για την αρχική οθόνη κινητού |
| `sw.js` | Λειτουργία χωρίς internet |
| `tests/` | Αυτόματες δοκιμές (δεν χρειάζεται για τη λειτουργία, μπορεί να ανέβει ή όχι) |

## Ανέβασμα δωρεάν στο GitHub Pages

1. Φτιάξτε δωρεάν λογαριασμό στο github.com.
2. Πατήστε **New repository**, όνομα π.χ. `panellabels`, επιλέξτε **Public**, πατήστε **Create repository**.
3. Πατήστε **uploading an existing file** και σύρετε **όλα τα αρχεία και τον φάκελο `icons`** (το περιεχόμενο του zip, όχι το ίδιο το zip). Πατήστε **Commit changes**.
4. Πηγαίνετε **Settings → Pages**. Στο **Branch** επιλέξτε `main` και φάκελο `/ (root)`, πατήστε **Save**.
5. Σε 1–2 λεπτά η εφαρμογή είναι στη διεύθυνση `https://ΟΝΟΜΑ-ΧΡΗΣΤΗ.github.io/panellabels/`.

## Εικονίδιο στο κινητό

- **iPhone (Safari):** ανοίξτε τη διεύθυνση → Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».
- **Android (Chrome):** ανοίξτε τη διεύθυνση → ⋮ → «Εγκατάσταση εφαρμογής».

## Νέα έκδοση

Όταν αλλάζετε αρχεία, ανεβάστε τα ξανά και αλλάξτε στο `sw.js` τη γραμμή `const CACHE = 'panellabels-1.2.0';` (π.χ. σε `1.2.1`). Οι συσκευές παίρνουν τη νέα έκδοση στο επόμενο άνοιγμα. Τα έργα των χρηστών δεν επηρεάζονται.

## Έλεγχος διαστάσεων

Πριν από πραγματική χρήση: Εκτύπωση → «Σελίδα δοκιμής διαστάσεων» → τύπωμα σε κλίμακα 100% → μέτρηση με χάρακα (οι γραμμές πρέπει να είναι 100 mm). Αν τα στοιχεία κάποιου κατασκευαστή διαφέρουν (π.χ. 18 mm), αλλάξτε το «Πλάτος μονάδας».

## Μελλοντικά (καταστήματα εφαρμογών)

- Η εφαρμογή μπορεί να «τυλιχτεί» με το δωρεάν Capacitor για Google Play / App Store χωρίς αλλαγές στη λογική.
- Τα δικαιώματα χρήσης περνούν από το αντικείμενο `Entitlements` στο `app.js`, ώστε να προστεθεί συνδρομή μέσω του καταστήματος χωρίς να αποθηκεύονται έργα σε δικό σας server.
- Στο τοπικό αποθηκευτικό, στην εφαρμογή καταστήματος, προτείνεται μεταφορά από `localStorage` σε αρχεία της συσκευής για μεγαλύτερη ασφάλεια.

## Εκτύπωση

Το κουμπί «Εκτύπωση» φτιάχνει το ίδιο PDF με το κουμπί «Δημιουργία PDF» και το ανοίγει για εκτύπωση: στο κινητό από το μενού κοινοποίησης («Εκτύπωση»), στον υπολογιστή σε νέα καρτέλα. Δεν χρησιμοποιεί την εντολή εκτύπωσης του browser, που στα κινητά συχνά δεν ανοίγει ή παγώνει.

## Δοκιμές

Στον φάκελο της εφαρμογής: `python3 -m http.server 8765` και σε άλλο παράθυρο `sh tests/run_all.sh`.
Χρειάζονται Python με `playwright` (chromium), `pypdf`, `pypdfium2`, `Pillow`.

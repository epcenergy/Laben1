# PanelLabels — δοκιμαστική έκδοση 0.1

Web εφαρμογή για δημιουργία ετικετών ηλεκτρικών πινάκων. Το GitHub Pages μπορεί να φιλοξενήσει τα αρχεία στατικά, χωρίς μηνιαία χρέωση για αυτή την απλή έκδοση.

## Δημοσίευση στο GitHub Pages

1. Δημιούργησε ένα νέο repository στο GitHub.
2. Ανέβασε τα αρχεία `index.html`, `.nojekyll` και `README.md` στη βασική (root) διαδρομή του repository.
3. Άνοιξε **Settings → Pages**.
4. Στο **Build and deployment**, επίλεξε **Deploy from a branch**.
5. Επίλεξε branch `main` και folder `/ (root)`, πάτησε **Save**.
6. Περίμενε να ολοκληρωθεί η δημοσίευση και άνοιξε το URL που θα εμφανίσει το GitHub Pages.

## Περιλαμβάνει

- Πολλαπλές σειρές και στοιχεία πλάτους 1, 1,5, 2, 3, 4, 5 ή 6 μονάδων.
- Περιγραφές και προαιρετικά σύμβολα.
- Αποθήκευση και άνοιγμα έργων στον browser της συσκευής.
- Στοιχεία ηλεκτρολόγου και προαιρετικό λογότυπο.
- Εξαγωγή/εισαγωγή backup JSON.
- Εκτύπωση μέσω browser / αποθήκευση σε PDF.

## Σημαντικές προειδοποιήσεις

- Αυτή είναι δοκιμαστική έκδοση, όχι τελικό προϊόν.
- Τα έργα και τα στοιχεία αποθηκεύονται τοπικά στον browser. Δεν υπάρχει συγχρονισμός μεταξύ συσκευών ή χρηστών.
- Αν καθαριστούν τα δεδομένα του browser ή χαθεί η συσκευή, τα τοπικά έργα μπορεί να χαθούν. Κάνε τακτικά **Εξαγωγή δεδομένων** και φύλαξε το backup σε ασφαλές σημείο.
- Το GitHub repository πρέπει να είναι δημόσιο για δωρεάν GitHub Pages σε προσωπικό λογαριασμό GitHub Free. Ο κώδικας θα είναι ορατός σε άλλους· μην ανεβάσεις στοιχεία πελατών ή backup.
- Για εκτύπωση, δοκίμασε αρχικά σε απλό χαρτί. Επίλεξε κλίμακα 100% / Actual size και απενεργοποίησε το “Fit to page”. Οι ονομαστικές διαστάσεις πρέπει να επαληθευτούν με πραγματικές δοκιμές.
- Η αποθήκευση έργων σε browser δεν είναι επαγγελματικό αντίγραφο ασφαλείας. Αυτή η έκδοση δεν πρέπει να θεωρηθεί ολοκληρωμένη πριν δοκιμαστούν όλες οι λειτουργίες σε πραγματικές συσκευές και εκτυπωτές.
